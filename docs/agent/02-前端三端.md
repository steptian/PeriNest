# 02 · 前端三端（Wing / Leg / Antenna）

**关键词索引**：React / Vite / zustand / TanStack Query / SSE / fetch reader / 暗色 / useTheme / BottomNav / 设计系统 / wx.request / 401 重登

## 三端同构模式（改一端先看另一端）

| 层 | Wing（Web 5173） | Leg（H5 5174，480px） | Antenna（小程序） |
|:---|:---|:---|:---|
| API 封装 | `wing/src/api/client.ts:10`（Axios 拦截器） | `leg/src/api/client.ts`（同构复制） | `antenna/miniprogram/utils/request.ts`（wx.request） |
| 登录态 | zustand persist `perinest-wing-auth` | 同构 `perinest-leg-auth` | Storage `perinest_token` |
| 401 处理 | 拦截器登出跳转 | 同构 | **静默重登重放**（`antenna/miniprogram/utils/request.ts:33` silentLogin） |
| 主题 | useTheme + CSS 变量 | 同构（key 独立） | app.wxss 亮色令牌（暂无暗色） |

## SSE 流式消费（两端一致的实现模式）

`leg/src/api/ai.ts:14`（Wing 同构）：fetch + `resp.body.getReader()` + TextDecoder，按行解析 `data:` JSON，逐 delta 回调 → 打字机效果。**不用 Axios**（EventSource 不支持 POST header）。

## 设计系统（琥珀标本馆）

- 令牌单源：`wing/src/index.css` / `leg/src/index.css`（`:root` 亮 `:root+.dark` 暗，变量集两端一致）
- 核心类：`.specimen-card`（标本卡+琥珀铆钉）、`.font-specimen`（Fraunces+宋体栈）、`.specimen-latin`（图鉴小字）、`.btn-amber`（琥珀渐变）、`.amber-caret`（呼吸光标）、`.msg-in`（入场动画）
- 防闪白：`index.html` 内联脚本渲染前恢复主题 class
- 坑：Vite dev 监听 IPv6 localhost——联调 curl 用 `http://localhost:5173` 而非 127.0.0.1 ℹ️

## 截图管线（README 演示图）

`scripts/take_screenshots.py`：Playwright 设备视口（390×844 / 1440×900）→ localStorage 注入登录态 → chat 页发消息等流式稳定 → 截图到 `assets/screenshots/`。重拍：起 queen+双 dev 后 `python3 scripts/take_screenshots.py [all|leg|wing]`。
