## 琥珀毛玻璃设计系统（三端统一，v0.9.x）

- 令牌：`--glass-bg/blur/border/hi` 四件套（✅ `wing/src/index.css:22`、`leg/src/index.css:33`；Antenna wxss 平行 `antenna/miniprogram/app.wxss:31`），亮色米纸玻璃/暗色深琥珀玻璃
- **毛玻璃可见前提**：body 加琥珀光斑氛围层（3 团 radial-gradient，亮暗分色阶）——没有背景光玻璃透不出东西
- `.glass` 通用表面类 + `.specimen-card` 玻璃化（标本铆钉保留）；**输入框保持实底**（输入清晰优先）
- **表面二分法（用户验收确立）**：展示面（页面卡/侧栏）=玻璃；输入工作面（弹窗/抽屉/表单卡）=`.panel-solid` 实底（Modal/ConfirmDialog/AiAssistant/Login 均已实底）——半透明底与实底输入框对比突兀，可读性优先于氛围
- 降级：Web 用 `@supports not (backdrop-filter)` 回实底；Antenna 用 `@supports` 内再覆盖（部分安卓老内核无 backdrop-filter 自动回实底，`antenna/miniprogram/app.wxss:69`）
- 性能边界：只用于表面层（卡片/侧栏/弹层/底栏），**不嵌套**（子层 blur 不到原始背景）
- 约束：微信原生 tabBar/导航栏是微信渲染层，无法毛玻璃

## Antenna 特有坑（v0.9.x 新增）

- **switchTab 坑**：tabBar 页（index/order/chat/user）用 `navigator` 默认 navigateTo **静默失败**——必须 `open-type="switchTab"` 或 `wx.switchTab`（✅ `antenna/miniprogram/pages/index/index.wxml:11`）
- apiBase 开发环境用局域网 IP `192.168.3.74`（✅ `antenna/miniprogram/app.ts:10`）——真机预览 127.0.0.1 指向手机自身；IP 变了改这行
- 「我的」页身份走后端权威 `/auth/me`（✅ `antenna/miniprogram/pages/user/user.ts:21`）——旧版 userInfo 快照全项目无写入点，永显示"未入巢"
- 聊天输入：`textarea + auto-height` 多行自动扩展（✅ `antenna/miniprogram/pages/chat/chat.wxml:12`；textarea maxlength 默认 140 必须显式放开）；发送按钮 height=line-height 等值修微信 button 默认盒高偏移
- logo 用 PNG 不用 SVG：小程序 image 组件不渲染 SVG；**透明 PNG 必须查 alpha 像素验证**（qlmanage 转 SVG 强制白底，用 Playwright omit_background 重转）
